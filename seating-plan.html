Instructions

1. Preparation

  • Exam details: course code, name and exam name appear in the printed header.
  • Proctor: shown on screen only; the attendance sheet has a signature line.

2. Classrooms

  • Select one or more rooms.
  • Capacities are shown as normal / exam next to each room.

3. Configuration

  • Capacity mode: “Exam” reduces capacity (usually a half or a third) for spacing.
  • Packed: sorts by ID (seniors first) and fills front rows and aisles.
  • Spread: distributes students evenly across the room.

4. Data format

  • The CSV must contain ID, Name, Surname columns.
  • Use UTF-8 so Turkish characters print correctly.
  • “Download CSV template” gives a starting point.

5. Adjusting and printing

  • Drag and drop: after generating, drag a student onto another seat (occupied or empty) to swap.
  • Print attendance: list with signature and absent fields.
  • Print door plan: anonymous layout for posting on the door.
  • Print output is black and white by design.
